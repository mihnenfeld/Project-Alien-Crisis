# PAC Asset Library
The first release contains metadata and acquisition specs only. No licensed third-party binary assets have been copied in yet.

After a model is reviewed, store its original file plus textures in a named asset folder, build a Godot wrapper scene and update docs/assetlib/INVENTORY.csv.

Suggested categories: architecture, machinery, infrastructure, props, lighting, materials, decals. The directories will be created as each real asset is acquired.
